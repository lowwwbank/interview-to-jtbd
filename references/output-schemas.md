# Output Schemas

When asked to generate artifacts, use these Markdown schemas.

## 1. JTBD Map Schema

```markdown
# JTBD Map

## Job 1: [Short Title]
**Statement:** When [situation], I want to [motivation] so I can [expected outcome].
**Evidence:**
- > "Quote from user" (Source/Participant)
- [Summary of observed behavior]
**Current Workaround:** [How are they solving this now?]

## Job 2: [Short Title]
...
```

## 2. Opportunity Map Schema

```markdown
# Opportunity Areas

## Opportunity 1: [Area Name]
**Related Job:** [Link to Job from JTBD Map]
**The Unmet Need:** [What is currently failing?]
**Severity/Importance:** [High/Medium/Low based on user emotion/frequency]
**Evidence:**
- > "Quote showing frustration"
```

## 3. Product Brief / Hypothesis Backlog Schema

```markdown
# Product Hypotheses

## Hypothesis 1
**If we build:** [Potential Solution/Feature Direction]
**Then:** [User Group] will be able to better accomplish [Specific Job].
**We will know we are right when:** [Proposed Metric, e.g., time saved, adoption rate].
**Risk/Unknowns:** [What do we still need to figure out?]
```

## 4. Next Interview Plan Schema

```markdown
# Next Research Steps

**Open Questions:**
1. [Question about a contradiction found in the current data]
2. [Question to dig deeper into a poorly understood Job]

**Target Audience for Next Round:**
- [Specific demographic or behavioral profile needed based on gaps in current data]
```
